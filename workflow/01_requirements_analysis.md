# Step 01: 要件分析

## 目的

アプリケーションの要件を整理し、データベース設計の入力とする。

## 担当エージェント

`database-designer`

## 入力

- ユーザーからのヒアリング
- 既存ドキュメント（あれば）

## 実行手順

1. プロジェクト概要のヒアリング
2. 主要機能の特定
3. エンティティの洗い出し
4. データの関連性の整理
5. 非機能要件（想定データ量、パフォーマンス要件など）の確認

## 出力

`output/01_requirements.md`

```markdown
# 要件定義書

## プロジェクト概要
- プロジェクト名:
- 目的:

## 主要機能
1.
2.

## エンティティ一覧
| エンティティ | 説明 |
|-------------|------|
| | |

## エンティティ関連
- エンティティA 1:N エンティティB

## 非機能要件
- 想定データ量:
- パフォーマンス要件:
```

## 完了条件

- [ ] エンティティが特定されている
- [ ] エンティティ間の関連が明確
- [ ] 非機能要件が整理されている
